# Working in this repository with an AI agent

These rules are fixed. They apply to every commit, pull request, comment and branch an
agent produces here.

- **No agent attribution, ever.** No `Co-Authored-By:` trailer naming a model or
  assistant, no "Generated with" or "Generated by" line, and no session link
  (`claude.ai/code/session...` or similar) in a commit message, a PR title or body, a
  review comment, a code comment, or a file. CI fails the gate on a session link.
- **Commit as the repository author**, using the git identity already configured for
  this checkout. Never commit under an assistant identity.
- **Branch names follow the repo convention**: `fix/<topic>`, `docs/<topic>`,
  `sec/<topic>`. Never `claude/…`, `session-…`, or any name carrying a session id.
- Every behaviour change gets a `CHANGELOG.md` entry under `[Unreleased]`; the
  maintainer chooses the version at release time.
- Run `npm run typecheck`, `npx vitest run`, `npm run build`, and the repo's own gate
  (`node dist/cli/index.js check --staged`) before every push.
